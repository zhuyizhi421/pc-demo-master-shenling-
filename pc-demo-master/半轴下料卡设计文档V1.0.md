# 半轴下料卡配置 - 功能设计文档 V1.0

## 1. 功能概述

**功能名称**：半轴下料卡配置
**功能路径**：`#/basic-config/craftwork/semiAxleBlankingCard`
**功能描述**：用于配置和管理半轴下料卡数据，支持Excel导入导出、数据筛选、编辑删除等操作。
**数据存储**：本地 localStorage + Excel文件

## 3. 核心功能模块

### 3.1 数据加载机制

```
initData() → 优先从 localStorage 加载 → 无数据则从 public/semi-axle-blanking.xlsx 加载
```

- **本地优先策略**：页面加载时优先从 localStorage 读取数据
- **降级加载**：无本地数据时从 public 目录的 Excel 文件加载
- **自动去重**：加载数据时自动删除完全重复的行（排除序号字段）

### 3.2 筛选功能

**实现方式**：前端本地筛选（不请求后端）

**支持的筛选字段**：20个字段均支持列头筛选

**筛选逻辑**：
- 使用 `ColumnSearch` 组件实现列头筛选下拉
- 支持模糊匹配（不区分大小写）
- 每次输入即时筛选（@input 触发）
- 清除筛选按钮：仅在有筛选条件时显示

**重要：筛选数据隔离**
- 使用 `originalData` 保存原始数据副本
- 筛选操作基于 `originalData` 进行过滤
- 确保清除筛选后可恢复全部数据

### 3.3 自动计算字段

系统根据输入的原始字段自动计算以下字段：

```
料头长度 = 原材料长度 - (下料尺寸 + 锯片厚度) × 下料根数 - 套料数量 × 套料长度 - 锯片厚度 × 套料数量

尾料长度 = 料头长度 - 料头料尾切割厚度

材料利用率 = (原材料长度 - 料头长度) / 原材料长度 × 100%
```

**低利用率提醒**：材料利用率低于95%时，单元格显示特殊样式（红色背景）

### 3.4 导入功能

- 支持 `.xlsx` / `.xls` 格式
- 导入时自动去重
- 提供导入模板下载
- 导入后自动保存到 localStorage

### 3.5 导出功能

- 导出当前所有数据为 Excel 文件
- 文件名：`半轴下料卡.xlsx`

### 3.6 产品信息匹配

功能：从 BOM 文件匹配产品编号和产品名称

**匹配逻辑**：
1. 加载 BOM Excel 文件（支持 `云星空BOM(最终完成版)(1).xlsx` 或 `bom.xlsx`）
2. 创建 BOM 映射表（父项物料型号 → 产品编号、产品名称）
3. 根据"半轴型号"字段匹配产品信息
4. 自动填充"产品编号"和"产品名称"字段

## 5. 页面交互流程

### 5.1 首次使用流程

1. 用户打开页面 → 显示空表格（提示导入）
2. 点击「导入」按钮 → 选择 Excel 文件
3. 系统解析 Excel → 去重处理 → 保存到 localStorage
4. 表格显示数据

### 5.2 筛选流程

1. 点击列头筛选图标 → 展开搜索下拉
2. 输入搜索条件 → 实时筛选
3. 点击「清除筛选」→ 恢复显示全部数据

### 5.3 新建流程

1. 点击「新建下料卡」按钮 → 弹出新建对话框
2. 选择「产品名称」（下拉选择已有产品，支持搜索和创建新产品）
3. 选择产品后自动带出「产品编号」和「半轴型号」
4. 可选择/输入其他字段 → 点击保存
5. 系统计算自动字段（料头长度、尾料长度、材料利用率）→ 保存数据

### 5.4 编辑流程

1. 点击行内「编辑」按钮 → 弹出编辑对话框
2. 选择「半轴型号」后自动填充已有数据
3. 修改表单数据 → 点击保存
4. 系统重新计算自动字段 → 更新数据

## 7. 注意事项

1. **筛选与原始数据**：修改 `allData` 时必须同步更新 `originalData`，否则清除筛选功能会失效
2. **自动计算**：新建/编辑数据后必须调用 `calculateFields()` 计算派生字段
3. **本地存储**：所有数据保存在浏览器 localStorage，刷新不丢失
4. **BOM 匹配**：需确保 BOM 文件存在于 public 目录
