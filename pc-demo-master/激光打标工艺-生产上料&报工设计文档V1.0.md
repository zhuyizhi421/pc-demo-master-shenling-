# 激光打标工艺-生产上料&报工设计文档 V1.0

## 1. 功能概述

### 1.1 业务背景
激光打标工序来料是去氧化皮工序的后物料，装载方式是整框运输过来。操作流程为：
1. 扫描载具码/批次码实现批次上料
2. 线下完成激光打标
3. 操作工扫描产品上的单件码，实现在系统里面登记单件码信息以及该单件码的来源批次信息确保质量追溯完整
4. 单件扫码成功后即完成单件报工

### 1.2 功能目标
在现有生产详情页面的基础上，针对激光打标工艺进行改造：
1. 上料区：保持扫描物料条码上料（与下料工艺一致）
2. 报工区：改为扫描单件码自动报工
3. 追溯信息：记录单件码、来源批次、报工时间

### 1.3 使用场景
- 激光打标车间操作工进行上料和报工作业
- 质量追溯需要完整的来源批次信息

## 2. 作业流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        激光打标生产作业流程                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌──────────────┐     ┌──────────────┐     ┌──────────────┐ │
│  │   1. 上料    │ ──▶ │   2. 打标    │ ──▶ │   3. 报工    │ │
│  └──────────────┘     └──────────────┘     └──────────────┘ │
│        │                                           │            │
│        ▼                                           ▼            │
│  扫描物料条码                                  扫描单件码      │
│  批次上料                                     自动报工        │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 2.1 上料流程
1. 在上料区扫描物料条码（如 ML2.05.01.391-OP3020260924001）
2. 系统判断物料是否在物料清单（BOM）内
   - 在BOM内：直接上料
   - 不在BOM内：弹出授权提示，授权成功后上料
3. 物料添加到上料列表，默认数量为100

### 2.2 报工流程
1. 在报工区扫描单件码（如 SN-20260924001）
2. 系统自动匹配有剩余数量的批次
3. 自动扣减批次剩余数量 -1
4. 生成报工记录，包含追溯信息
5. 清空输入框，可连续扫描下一个

## 5. 功能交互

### 5.1 上料交互
1. 在上料区输入框扫描物料条码
2. 按回车键确认
3. 系统判断物料是否在BOM内：
   - 是：直接添加到上料列表，数量默认为100
   - 否：弹出授权提示，授权成功后添加
4. 上料成功后物料显示在上料列表

### 5.2 撤料交互
1. 点击物料行的"撤料"按钮
2. 弹出撤料确认弹窗，显示物料信息
3. 输入撤料数量（默认等于剩余数量）
4. 点击"确认"完成撤料
5. 撤料后：
   - 剩余数量 > 0：更新物料数量
   - 剩余数量 = 0：从列表移除

### 5.3 单件扫码报工交互
1. 在报工区扫描单件码（如 SN-20260924001）
2. 按回车键确认（扫码枪自动发送回车符）
3. 系统自动匹配有剩余数量的批次
4. 自动执行：
   - 扣减批次剩余数量 -1
   - 增加已报工数量 +1
   - 生成报工记录（含追溯信息）
5. 清空输入框，准备下次扫描

### 5.4 报工列表显示
1. 报工成功后，数据显示在报工列表区域
2. 显示字段：产品型号、单件码、来源批次、状态、报工人、报工时间
3. 可进行"补打标签"操作

## 6. 技术实现

### 6.1 涉及文件

| 文件路径 | 说明 |
|---------|------|
| `src/views/ProductionDetailView.vue` | 生产详情页面，包含上料和报工逻辑 |

| `src/components/WithdrawMaterialModal.vue` | 撤料确认弹窗组件 |

### 6.2 组件说明

#### ProductionDetailView.vue
- `isLaserMarkingProcess` 计算属性：判断是否为激光打标工艺
- `singleCodeInput` 变量：单件码输入
- `handleSingleCodeScan` 函数：处理单件码扫描报工
- 报工列表根据工艺类型显示不同列

### 6.3 核心逻辑

#### 激光打标判断逻辑
```javascript
const isLaserMarkingProcess = computed(() => {
  const process = currentTask.value?.process || ''
  return process.includes('激光打标')
})
```

#### 单件扫码报工逻辑
```javascript
const handleSingleCodeScan = () => {
  // 1. 查找有剩余数量的批次
  const availableBatch = materialRows.value.find(row => row.remainingQty > 0)

  // 2. 扣减批次剩余数量
  availableBatch.remainingQty -= 1
  availableBatch.usedQty += 1

  // 3. 生成报工记录（含追溯信息）
  reportRowsMap.value[orderNo].push({
    singleCode: singleCode,          // 单件码
    sourceBatchNo: availableBatch.batchNo,  // 来源批次
    materialCode: availableBatch.materialCode  // 物料编号
  })

  // 4. 保存数据
  saveMaterialRows()
  saveReportRows()

  // 5. 清空输入
  singleCodeInput.value = ''
}
```

## 7. 边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 扫描单件码时无可用批次 | 提示"无可用批次，请先上料" |
| 物料不在BOM内 | 弹出授权提示，需要授权后才能上料 |
| 报工后批次剩余数量为0 | 从上料列表移除该批次 |
| 撤料后剩余数量为0 | 从上料列表移除该物料 |
